# 1. 前言

## 1.1 OLA 是什么？

**OLA 是一个帮您把跨境 B2B 销售订单"从询盘到成交、再到续约"全流程跑完的 AI 助手。**

![OLA 功能概览](/img/cn/workflow/1.1.png)

1. **听**：听懂您和客户在电话里、微信里、邮件里说了什么（支持普通话 / 粤语 / 英语，以及它们的混杂）
2. **记**：把每次互动自动整理进每个客户的"持续画像"——客户是谁、要什么、在乎什么、决策风格如何
3. **干**：替您写报价单、回询盘、做跟进、提醒续约——并且报价的每一分钱都来自您真实的产品目录，不是 AI 编的
4. **教**：在您打电话、写邮件的时候，实时提示您"客户刚才提的这个顾虑，建议这样回应"

---

## 1.2 OLA 与其他销售工具有什么不一样？

| 问题 | OLA |
|------|-----|
| 手动录入，数据残缺 | 自动从通话/邮件/WhatsApp 抓取 |
| 客户资料是通话索引，新人难接手 | 持续客户画像，30 秒上手 |
| 只给洞察，报价还得自己写 | 直接从真实目录生成报价单，一键发送 |
| 只支持英文 | 普通话 / 粤语 / 英语混杂原生支持 |
| 多工具拼凑，成本叠加 | 一个 agent 跑通询盘到续约，成本约十分之一 |
| AI 报价会编数字，销售不敢用 | 确定性报价，每个数字可追溯，零幻觉 |

## 1.3 OLA 的三层架构

OLA 是由三层能力组成的完整系统：

![OLA 三层架构](/img/cn/workflow/1.3.png)

```
┌─────────────────────────────────────────────────────┐
│  L1 · 通道捕获（让数据自动流进来）                   │
│  通话录音  WhatsApp  邮件询盘  网页表单  面访         │
└─────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────┐
│  L2 · 客户画像（持续更新的客户大脑）                  │
│  需求/偏好  异议/顾虑  价格敏感度  决策风格  漏斗阶段  │
└─────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────┐
│  L3 · 执行自动化                                     │
│  询盘应答  报价生成  实时教练  续约外联               │
└─────────────────────────────────────────────────────┘
```

- **L1 · 数据**：自动抓取通话、邮件、WhatsApp 里的信息，销售不用改变任何工作习惯。
- **L2 · 画像**：信息自动整合成每个客户的持续画像，属于公司，不随销售离职流失。
- **L3 · 执行**：基于画像，在漏斗各阶段自动替您干活——回询盘、出报价、跟进续约。

**AskOLA 是您与这三层交互的入口**，本指南从这里开始。
