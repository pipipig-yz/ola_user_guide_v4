# 2. 智能助手 AskOLA

AskOLA 是您日常和 OLA 打交道的主要入口。无论您想查信息、改资料、新建记录，都可以在这里用一句话搞定，不用点菜单、不用学操作。

本章分三节：

- **[2.1 查询信息](/cn/askola/search)**：查客户、查商品、查报价单
- **[2.2 修改信息](/cn/askola/edit)**：改资料、改价格、改报价单
- **[2.3 录入新信息](/cn/askola/create)**：建客户、建商品、建报价单

---

## 打开 AskOLA

登录 OLA 系统后，点击左侧导航栏的 **AskOLA** 进入对话界面。

您可以在系统任意页面随时打开它，不影响您正在做的其他操作。
